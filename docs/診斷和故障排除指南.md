- 確認 SQL Server 服務器 IP 正確

### 第二步: 測試 SQL Server 連接

```powershell
$connStr = "Data Source=192.168.1.111;Initial Catalog=Pi news;User ID=sa;Password=!QAZxsw2;Connection Timeout=60;TrustServerCertificate=true;Encrypt=true"

$conn = New-Object System.Data.SqlClient.SqlConnection
$conn.ConnectionString = $connStr

try {
    Write-Host "正在連接 SQL Server..."
    $conn.Open()
    Write-Host "? SQL Server 連接成功！"
    
    # 嘗試執行簡單查詢
    $cmd = $conn.CreateCommand()
    $cmd.CommandText = "SELECT 1"
    $result = $cmd.ExecuteScalar()
    Write-Host "? SQL Server 查詢成功！結果: $result"
    
    $conn.Close()
} catch {
    Write-Host "? SQL Server 連接失敗："
    Write-Host $_.Exception.Message
    if ($_.Exception.InnerException) {
        Write-Host "內層異常: $($_.Exception.InnerException.Message)"
    }
}
```

### 可能的連接問題及解決方案

| 錯誤信息 | 原因 | 解決方案 |
|---------|------|---------|
| "Connection timeout" | 網絡無法到達或 SQL Server 無響應 | 1. 檢查 IP 2. 檢查 SQL Server 狀態 |
| "Login failed" | 認證失敗 | 確認用戶名/密碼正確 |
| "Named Pipes Provider could not open a connection" | 命名管道未啟用 | 在 SQL Server 啟用 TCP/IP 協議 |
| "SSL/TLS handshake failure" | 證書問題 | 確認已設置 `TrustServerCertificate=true` |

## ?? SQL Server 連接檢查清單

如果上面的 PowerShell 測試失敗，請逐項檢查：

### 基礎檢查
- [ ] **SQL Server 是否在線?** 
  - 在 SQL Server 所在服務器上運行: `sc query MSSQLSERVER`
  - 應該看到 STATE: 4 RUNNING

- [ ] **SQL Server 是否使用 TCP/IP?**
  - 打開 SQL Server Configuration Manager
  - 確認 TCP/IP 已啟用
  - 確認使用默認端口 1433

- [ ] **防火牆是否阻止 1433 端口?**
  - Windows 防火牆應該允許 SQL Server (通常已自動設置)
  - 如果在局域網，檢查網絡防火牆

- [ ] **認證信息是否正確?**
  - 用戶名: `sa`
  - 密碼: `!QAZxsw2`
  - 數據庫: `Pi news` (注意名稱中有空格)

### 進階檢查 (在 SQL Server 服務器上)

```sql
-- 1. 檢查 sa 用戶是否啟用
SELECT name, is_disabled FROM sys.sql_logins WHERE name = 'sa';

-- 2. 檢查數據庫是否存在
SELECT name FROM sys.databases WHERE name = 'Pi news';

-- 3. 檢查連接
SELECT * FROM sys.dm_exec_connections;
```

- 性能優化代碼也會被測試

#### 選項 C: 使用 Fallback 策略 (最佳實踐)

修改 Program.cs 在連接失敗時自動降級到 Demo Mode:

```csharp
// 嘗試連接到 SQL Server
bool canConnectToDb = true;
try {
    using (var conn = new SqlConnection(connectionString)) {
        conn.Open();
    }
} catch {
    canConnectToDb = false;
    _logger.LogWarning("無法連接到 SQL Server，切換到 Demo Mode");
}

if (!canConnectToDb || useDemoMode) {
    // 使用 Demo Mode
} else {
    // 使用實際數據庫
}
```
